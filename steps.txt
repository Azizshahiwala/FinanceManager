-Now lets use db.sqlite!
-we can create tables using models. Any table is created using 'class' keyword and the file becomes a model.

Find models.py inside your app. Then create tables like this:

class Course(models.Model):
    name = models.CharField(max_length=50)
    duration = models.CharField(max_length=50)
    description = models.TextField(max_length=255)

Note, i don't need to write __init__ myself, models.Model already gives one. i used:

CharField 
TextField

FORMS + REGISTER_STUDENT
-----------------
-inside StudentRegister.html, i used {{form.as_p}} to print the form.
-this auto-generates html for each field, wrapped in <p> tags (label+input+errors). other options are .as_table and .as_ul.

-noticed name and email fields print as big boxes (textarea) instead of normal input.
-reason: in models.py i used TextField for name/email instead of CharField.
-Django maps TextField -> <textarea>, CharField -> <input type="text">. enrollment is CharField so it prints small, name/email are TextField so they print big.

-Now, i want a page where student can register. so instead of writing my own validation, i use ModelForm.

-Find forms.py inside your app (create if not there). then bind it to your model:

from django import forms
from .models import *

class StudentForm(forms.ModelForm):
    class Meta:
        model = Student
        fields= ['enrollment','name','email']

-this saves me from writing manual validation and manual db insert. it auto-generates fields based on model, validates using the model's rules (like max_length), and form.save() directly writes to db.

-Now in views.py, i import this form and write register_student:

from .forms import *

def register_student(request):
    if request.method == 'POST':
        form = StudentForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect('login/')
    else:
        form = StudentForm()
    return render(request,'StudentRegister.html',{'form':form})

-step by step what this does:
1. check request.method. if its POST, means student submitted the form.
2. bind submitted data (request.POST) to StudentForm.
3. form.is_valid() runs validation. if valid, form.save() creates Student row in db.
4. after saving, redirect to login page.
5. if request is GET (just opening page) or form invalid, show blank/same form back using render.

-note: request.POST is uppercase, not request.post. python/django is case sensitive here.
